# Wordplay for Claude, for the test site

This branch is the Wordplay plugin built for the test site,
[test.wordplaylabs.com](https://test.wordplaylabs.com), where changes are
tried before they reach [wordplaylabs.com](https://wordplaylabs.com). For
the site's own plugin, see the `main` branch.

```
claude plugin marketplace add JavierMNieto/wordplay-labs-plugin#test
claude plugin install wordplay-test@wordplay-test
```

Published from Wordplay's own repository each time its test branch moves;
changes made here are replaced. MIT licensed: see [LICENSE](LICENSE).
