# Wordplay for the test site

The Wordplay plugin, built for https://test.wordplaylabs.com. It differs from the site's own
plugin, `wordplay`, only in this:

- its name is `wordplay-test`, so its commands are `/wordplay-test:…`;
- it writes to, and previews against, https://test.wordplaylabs.com;
- it is published to this repository's `test` branch, as the marketplace
  `wordplay-test`, where `wordplay` is published to `main`.

What the plugin holds and how to use it is the site's plugin's README.
